# Cursor Desktop — что доделать на твоей стороне

Туннель в Польшу я уже проверил (работает). Осталось то, что можно сделать **только на твоём Windows‑ПК в десктопном Cursor**. Пройди по чек‑листу и пришли мне результат отмеченных пунктов.

> Версия сборки: **1.0.9** (`utils/app.version`). Файл скачивай из готового архива `Otmena-cursor-europe-v1.0.9.zip`.

---

## A. Включить туннель (1 раз)

- [ ] 1. Распаковал Otmena в обычную папку (например `C:\Otmena\`, **не** в `Program Files`).
- [ ] 2. Запустил **`CURSOR-EUROPE-ON.bat`** (ПКМ → «Запуск от имени администратора»).
- [ ] 3. В чёрном окне появилась строка проверки. **Пришли мне эту строку.** Ожидаемо:
      `Proverka OK: vyhod 45.144.48.81 Warsaw PL (ne Rossiya).`
      Если там `RU` или ошибка `Tunnel ne podnyalsya` — тоже пришли, это и есть симптом.

## B. Проверить, что Cursor реально видит прокси

- [ ] 4. **Полностью** закрой Cursor (через трей тоже, не просто окно).
- [ ] 5. Открой Cursor заново.
- [ ] 6. `Ctrl+Shift+P` → набери **Preferences: Open User Settings (JSON)** → Enter.
- [ ] 7. Проверь, что там есть строки (это пишет наш скрипт):
      ```json
      "http.proxy": "http://127.0.0.1:10809",
      "http.proxySupport": "on"
      ```
      Если их нет — напиши, добавим вручную/разберёмся почему не записалось.
- [ ] 8. (доп.) `Ctrl+Shift+P` → **Developer: Toggle Developer Tools** → вкладка **Network**. Сделай любой запрос к модели в чате Cursor и посмотри, идут ли запросы (не красные/timeout).

## C. Боевая проверка моделей

- [ ] 9. Открой чат в Cursor, выбери модель и отправь любое сообщение («привет»).
- [ ] 10. Напиши мне: **какие модели отвечают, а какие нет** (и какой текст ошибки у тех, что не работают — точную формулировку/скриншот).
- [ ] 11. Если модель/агент **серого цвета или «недоступен в регионе»** — укажи название модели. (Если модель просто отсутствует в твоём тарифе — это аккаунт Cursor, прокси тут не поможет.)

## C2. Ошибка «This model provider is not supported in your region»

Это значит, что прокси **уже работает** (Cursor достучался до сервера), но определил регион как заблокированный. Почти всегда причина — **HTTP/2**: с ним часть запросов Cursor идёт **мимо прокси** и светит твой реальный IP МТС. Лечение уже встроено в `cursor-europe.ps1` / `cursor-proxy.ps1` (пишет нужные настройки), но проверь руками:

- [ ] 1. Открой `settings.json` (`Ctrl+Shift+P` → Open User Settings (JSON)) и убедись, что есть **все 4 строки**:
      ```json
      "http.proxy": "http://127.0.0.1:10809",
      "http.proxySupport": "override",
      "http.proxyStrictSSL": false,
      "cursor.general.disableHttp2": true
      ```
      `http.proxySupport` должен быть именно **`override`** (форсит прокси), а не `on`. Если стоит `on` или нет `disableHttp2` — перезапусти `CURSOR-EUROPE-ON.bat` (он перезапишет) или добавь вручную.
- [ ] 2. **Полностью** перезапусти Cursor (через трей).
- [ ] 3. В выборе модели поставь **Auto** или попробуй свежую модель (новые модели типа Sonnet 4.x / GPT‑5.x реже режут по региону, чем старые).
- [ ] 4. Если всё ещё блокирует: проверь, что выход реально Польша — открой в Cursor встроенный терминал и выполни
      `curl -x http://127.0.0.1:10809 https://ipinfo.io/json` — должно показать `"country": "PL"`.
- [ ] 5. Если выход PL, HTTP/2 off, а модель всё равно недоступна — пришли мне название модели: возможно, добавим выходной сервер в другой стране (Польша поддерживается, но под отдельные модели иногда нужен другой регион ЕС/США).

> Важно: **не** добавляй `*.cursor.sh` / `*.cursor.com` в обход прокси — наоборот, их трафик должен идти через Польшу, чтобы Cursor видел европейский IP.

## D. Выключение (когда нужно)

- [ ] Запусти **`CURSOR-EUROPE-OFF.bat`** — вернёт прямое соединение и уберёт прокси из Cursor. Затем перезапусти Cursor.

## E. Для тебя как maintainer (по желанию, чтобы кнопка «Обновления» работала)

Сейчас на GitHub последний релиз — **v1.0.8**, а в этой сборке стоит **1.0.9**. Пока ты не выложишь v1.0.9, **не жми «Обновления» в Otmena** — иначе она переустановит 1.0.8 (твой `config.json` и `xray.exe` сохранятся, но `launcher.ps1` откатится).

Чтобы выпустить v1.0.9 нормально (на Windows, нужен `gh auth login`):
```powershell
cd app
.\build-app.ps1
cd ..\utils
.\publish-update.ps1 -GitHubRepo "Qylosez/otmena-releases" -Bump
```
